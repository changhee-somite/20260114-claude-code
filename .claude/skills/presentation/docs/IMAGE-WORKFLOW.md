# Image Insertion Workflow

This document describes how to insert images into presentations generated by the PPTX skill's template-based workflow.

## Overview

The standard PPTX skill workflow generates presentations with text content only. This enhanced workflow adds a post-processing step to insert images at specified positions.

```
Standard workflow:
PRESENTATION.md → rearrange.py → replace.py → output.pptx (text only)

Enhanced workflow:
PRESENTATION.md → rearrange.py → replace.py → working.pptx
                                                    │
figures/ + image-mapping.json ──────────────────────┼──→ insert_images.py → final.pptx
```

## Scripts

### analyze_slides.py

Analyzes slides to help plan image placement.

```bash
# Analyze entire presentation
python workspace/analyze_slides.py presentation.pptx

# Analyze specific slide
python workspace/analyze_slides.py presentation.pptx --slide 5
```

**Output includes:**
- Presentation dimensions
- Available slide layouts
- Existing shapes and their positions
- Suggested areas for image placement

### insert_images.py

Inserts images based on a JSON mapping file.

```bash
python workspace/insert_images.py <input.pptx> <mapping.json> <output.pptx>
```

**Example:**
```bash
python workspace/insert_images.py \
  "20260114 Claude-Code-Presentation-v2.pptx" \
  workspace/image-mapping.json \
  "final-presentation.pptx"
```

## Image Mapping JSON Format

### Basic Structure

```json
{
  "slides": [
    {
      "slide_number": 5,
      "description": "Optional description",
      "images": [
        {
          "path": "figures/diagram.png",
          "preset": "right_half"
        }
      ]
    }
  ]
}
```

### Position Presets

Use presets for common layouts:

| Preset | Description |
|--------|-------------|
| `right_half` | Image fills right half of slide (text-left/image-right) |
| `left_half` | Image fills left half of slide (image-left/text-right) |
| `bottom_half` | Image fills bottom half of slide |
| `center` | Image centered, max 80% of slide dimensions |
| `full` | Image fills entire slide (background) |

**Example with preset:**
```json
{
  "path": "figures/screenshot.png",
  "preset": "right_half"
}
```

### Custom Positioning

For precise control, specify position and size in inches:

```json
{
  "path": "figures/diagram.png",
  "left": 6.5,
  "top": 1.5,
  "width": 6.0,
  "height": null
}
```

**Position/size rules:**
- All values are in inches
- `left`, `top`: Position from top-left corner
- `width`, `height`: Image dimensions
- If `width` is `null`, aspect ratio is preserved based on `height`
- If `height` is `null`, aspect ratio is preserved based on `width`
- If both are `null`, original image size is used (at 96 DPI)

### Multiple Images Per Slide

```json
{
  "slide_number": 10,
  "images": [
    {
      "path": "figures/left-image.png",
      "preset": "left_half"
    },
    {
      "path": "figures/right-image.png",
      "preset": "right_half"
    }
  ]
}
```

## Workflow Example

### Step 1: Generate Text-Only Presentation

Use the standard PPTX skill workflow to generate a presentation from PRESENTATION.md.

### Step 2: Analyze Slides for Image Placement

```bash
cd workspace
python analyze_slides.py "../Claude-Code-Presentation-v2.pptx" --slide 5
```

Review the output to understand existing content positions.

### Step 3: Create Image Mapping

Create `workspace/image-mapping.json` with your figure mappings:

```json
{
  "slides": [
    {
      "slide_number": 5,
      "description": "Blog screenshot",
      "images": [
        {
          "path": "../figures/Slide005-blog-screenshot.png",
          "preset": "right_half"
        }
      ]
    }
  ]
}
```

### Step 4: Insert Images

```bash
python insert_images.py \
  "../Claude-Code-Presentation-v2.pptx" \
  "image-mapping.json" \
  "../final-presentation.pptx"
```

### Step 5: Verify Output

Open the output file in PowerPoint/Keynote to verify image placement.

## Figure Naming Convention

For easy tracking, name figures with their target slide number:

```
figures/
├── Slide005-blog-screenshot.png
├── Slide006-reddit-post.png
├── Slide015-status-usage.png
└── Slide027-config-screen.png
```

This makes it easy to create the image mapping and maintain consistency.

## Troubleshooting

### Image not appearing

1. Check the file path in the JSON (relative to the JSON file location)
2. Verify the image file exists
3. Check slide number is correct (1-indexed)

### Image position is wrong

1. Use `analyze_slides.py` to see existing content positions
2. Adjust preset or use custom positioning
3. Remember: (0, 0) is top-left corner

### Image is cropped or stretched

- Use `preset` for automatic aspect ratio handling
- Or set only `width` OR `height` (not both) to preserve aspect ratio

### Output file is corrupted

- Ensure input PPTX is not open in another application
- Try with a fresh copy of the input file
