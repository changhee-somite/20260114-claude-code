## /status Command Screenshots

These screenshots demonstrate the `/status` command in Claude Code, which provides real-time information about your session, configuration, and usage.

### status-tab-status.png
**What it shows:** The Status tab of `/status` command
- Version: 2.1.7
- Session ID
- Working directory
- Login method: Claude Max Account
- Organization info
- Model: Default Opus 4.5
- MCP servers: plugin:context7, plugin:github
- Memory: project CLAUDE.md
- Setting sources

**Use in presentation:** Demonstrating session information and MCP integration

### status-tab-config.png
**What it shows:** The Config tab of `/status` command
- Auto-compact: true
- Show tips: true
- Thinking mode: true
- Prompt suggestions: true
- Rewind code (checkpoints): true
- Theme: Dark mode
- Model: Default (recommended)
- Various other settings

**Use in presentation:** Showing configurable options and preferences

### status-tab-usage.png
**What it shows:** The Usage tab of `/status` command
- Current session: 24% used (resets at 11:59am)
- Current week (all models): 5% used
- Current week (Sonnet only): 0% used

**Use in presentation:** Context window monitoring and usage tracking
