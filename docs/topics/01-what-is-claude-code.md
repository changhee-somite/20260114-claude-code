# What is Claude Code?

## Summary
Claude Code is not just a coding tool - it's a **general agent for computer automation**. At its core, it's an LLM that has been given permission to access a file system and execute commands.

## Timeline

| Date | Milestone |
|------|-----------|
| February 2025 | Initial launch as CLI research preview with Claude Sonnet 3.7 |
| May 2025 | Public launch; revenue acceleration begins |
| October 2025 | Web launch on claude.ai (Oct 20) |
| November 2025 | $1B run-rate revenue milestone |
| January 2026 | Claude Code 2.1.0 with multi-agent infrastructure |

## The "General Agent" Concept

Simon Willison's key insight: Claude Code should be thought of as a tool for **"anything you can achieve by typing commands into a computer"** rather than just coding.

> "2025 has become the year of agents... agents are 'tools in a loop'"
> — Simon Willison

### What Makes It Different from Traditional IDEs

1. **File System Access**: Direct read/write to any file
2. **Command Execution**: Run any shell command
3. **Context Awareness**: Understands project structure
4. **Autonomous Operation**: Can work on tasks with minimal supervision

## The Simplicity Principle

The power comes from simplicity:
- LLMs excel at reading text and using available tools
- No heavyweight protocols needed (contrast with MCP overhead)
- Skills are just markdown files with instructions
- "Outsources the hard parts to the LLM harness and the associated computer environment"
